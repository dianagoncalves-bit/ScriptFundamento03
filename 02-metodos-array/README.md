# JavaScriptFundamento03

Continuação dos estudos de JavaScript com foco em funções, métodos de array, objetos, JSON e introdução à Programação a Objetos.

## Objetos

Ao final do projeto, o aluno deverá ser capaz de:

- Criar e utilizar funções;
- Trabalhar com parâmetros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Trabalhar com array de objetos;
- Entender o uso de `this`;
